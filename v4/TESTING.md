# V4 版本功能与可访问性测试清单

本测试清单旨在为家长辅助功能、轻量物理引擎、自适应难度级别（Level Director）、Calm Mode 和可访问性指标提供详细的测试指导，方便后续迭代开发时的持续验收。

---

## 1. 游戏玩法与自适应测试清单
- [ ] **开局保护（Onboarding）**
  - 开始游戏后的前 2 秒（120 帧）内，确认画布上没有任何花藤障碍物。
  - 画布中应合理出现 1-2 颗位置显眼、易于收集的普通引导星星。
  - 屏幕中央弹出轻量提醒：“轻轻点击，让小蝴蝶飞起来 🦋”。
- [ ] **自适应难度（Adaptive Difficulty）**
  - **连续碰撞 2 次后**：下一次生成的障碍物间距（gap）在当前设定的基础上扩大 `+20px` 的安全缓冲区。
  - **连续碰撞 3 次后**：确认顶部弹出鼓励语句：“慢一点也没关系，稳稳飞 🦋”，且该提示每局游玩中最多出现一次。
  - **连续通过 5 组障碍后**：彩虹星星的出现几率应稍有提高（自适应逻辑将几率提升至 50%）。
- [ ] **游戏模式差异**
  - **练习课**：蝴蝶触碰障碍物和草地时不会扣除生命值（无限生命），且没有失败逻辑。
  - **花园课/冒险课/彩虹挑战**：按各自的心数生成心形图标（花园课 5 颗，其他 3 颗）。
  - 温柔模式自适应调整幅度应大于标准或高手模式。

---

## 2. Calm Mode (低刺激模式) 测试清单
- [ ] **屏幕震动（Screenshake）**
  - 开启低刺激模式时，金币收集和发生碰撞时的画布震动应完全消失（`screenShake = 0`）。
- [ ] **动画频率减慢**
  - 彩虹星星的 hue 色彩自转更新速度应有明显减慢。
- [ ] **粒子数量减少**
  - 碰撞或收集星星时产生的花粉粒子总数应降低 50% 以上。
- [ ] **Parallax 滚动弱化**
  - 背景的云朵、小山、近景花草的相对滚动速度减少 50% 以上。
- [ ] **鼓励语动画弱化**
  - 弹出鼓励提示框时，移除 `bounceIn` 等缩放动效，以平滑淡入或静止渲染。
- [ ] **音量降低**
  - 音频合成增益整体衰减 50%。

---

## 3. Reduced Motion (系统减少动效) 测试清单
- [ ] **环境检测**
  - 如果系统将 prefers-reduced-motion 设置为 reduce：
    - 游戏必须自动运行低刺激模式的表现。
    - 进入家长设置菜单时，应醒目地显示蓝色通知条：“检测到系统已开启减少动态效果，已自动为您优化动画体验。”
    - 本地设置开关不被强行改写，但游戏内所有动画效果与 Calm Mode 等效。

## 4. 可访问性 (Accessibility) 与 ARIA 测试清单
- [ ] **ARIA 属性覆盖**
  - 声音按钮 `sound-btn`：拥有 `role="switch"`，且 `aria-checked` 与 `aria-pressed` 属性的值必须与声音的开启状态（true/false）实时同步。
  - 难度选择卡片 `.btn-diff`：拥有 `role="radio"` 且更新 `aria-checked`。包裹它的父容器 `.diff-selector` 拥有 `role="radiogroup"` 属性。
  - 宝贝仓库标签 `.tab-btn`：拥有 `role="tab"`，且 `aria-selected` 在当前激活标签上为 "true"，`aria-controls` 指向对应的内容容器 ID。
- [ ] **触控目标大小**
  - 所有卡片、难度按钮、菜单选项、声音开关等可点交互目标在布局上的高度和宽度均不小于 `44px`。
- [ ] **色彩与对比度**
  - 确认所有辅助小字（如提示文字 `setting-tip`、锁定文本 `locked`、任务内容 `mission-text`）的颜色不要过浅（采用满足 WCAG 2.1 AA 对比度标准的色彩）。
- [ ] **无声游玩验证**
  - 关闭声音时，收集星星、穿过花藤、完成任务、阶段升级、游戏结束、 milestone 解锁都具有对应的视觉反馈。

## 5. 键盘与输入操作测试清单
- [ ] **Tab 遍历**
  - 能够使用键盘 Tab 键顺序聚焦到游戏界面的各个按钮，且拥有高亮的聚焦指示线（`focus-visible`）。
- [ ] **激活按钮**
  - 可以按 Enter 键或 Space 键触发已聚焦的按钮。
- [ ] **控制键行为**
  - 按 Space 键能控制蝴蝶向上飞行，但在输入寄语（`input`）或下拉选择框（`select`）中按下 Space 时**不应当**触发蝴蝶飞行。
  - 按 P 键能随时在“飞行中”与“暂停”状态之间切换。
  - 按 Esc 键可以关闭当前的“怎么玩”、“家长设置”或“宝贝仓库”面板。

## 6. Debug Panel (调参面板) 测试清单
- [ ] **隐藏开启**
  - 默认情况下不会显示任何 debug 控件。
  - 在首页或游戏中连续快速按下 **D 键 3 次** 应当开启/关闭调试面板。
  - 在 URL 结尾添加 query 参数 `?debug=1` 重新加载后应当自动开启。
- [ ] **碰撞检测框可视化**
  - 开启调试面板后，画布上显示：
    - 红色半透明的玩家蝴蝶物理碰撞圆圈。
    - 橙色半透明的花藤障碍物理碰撞矩形。
    - 绿色细线表示花藤通道的中心水平线。
    - 黄色半透明的星星拾取磁铁范围圈。
  - 关闭调试面板时，所有的物理边框线完全消失。
- [ ] **动态调参**
  - 拖动调试滑块改变各项系数值（如速度倍率、间距增量等），确认游戏中物体的移动和大小立即发生变化。
  - 调整后点击“复制 JSON”，确认剪贴板获取了正确的 overrides 键值。

## 7. 发布前自检（Self-check before push）
1. 本地通过浏览器访问：`/v4/` 首页，确认没有 console 报错。
2. 访问 `/v4/test.html`，确认所有的 Smoke Tests 测试用例结果都显示为 **PASS**。
3. 打开家长设置，点击重置最高分，确认在提示“再点一次”后能够成功清零。
4. 验证 V1 路径（`/legacy-v1/index.html`）、V2 路径（根目录 `index.html`）以及 V3 路径（`/v3/index.html`）依旧运行正常，逻辑和美术风格未受任何影响。
